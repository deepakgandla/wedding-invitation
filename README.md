# Wedding Invitation

A responsive Indian wedding invitation website built with vanilla HTML, CSS and JavaScript.

## Local preview

Run a static server from the repository root:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deployment

The GitHub Actions workflow publishes the site to GitHub Pages when changes are pushed to `main`. Enable **Settings → Pages → Build and deployment → Source → GitHub Actions**.

## Customization

Update `js/config.js` with the couple's names, event dates, venue, RSVP destination and other wedding details before publishing.

## Privacy

This repository and its GitHub Pages site are public. Do not commit private guest information or photographs unless you are comfortable making them publicly accessible.
